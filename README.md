# ArchyAFK

Modern, profesyonel ve yüksek performanslı bir Minecraft masaüstü istemcisi.

## Özellikler

- ⚡ React + TypeScript tabanlı modern arayüz
- 🖥️ Electron tabanlı Windows masaüstü uygulaması
- 🌙 Koyu tema odaklı tasarım
- 👤 Profil yönetimi
- 🏷️ Yerleşik kullanıcı adı oluşturucu
- 🌐 Sunucu durumunu görüntüleme
- 📊 Dashboard
- 📝 Log sistemi
- ⚙️ Ayarlar paneli

## Teknolojiler

- React
- TypeScript
- Vite
- Electron
- Tailwind CSS
- Zustand
- Framer Motion
